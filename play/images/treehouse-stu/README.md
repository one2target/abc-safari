# STU treehouse artwork

The 20 PNG files in this directory are the original artist-supplied files. Their filenames and transparent canvas were preserved exactly.

All files share a 1654 × 2205 pixel canvas (the delivered files differ from the 1536 × 2048 size stated in the brief, but have the same 3:4 aspect ratio). The game overlays every image at identical `inset: 0; width: 100%; height: 100%` coordinates and does not crop or trim transparent pixels.
