## Проверки через браузер

Оба сценария пройдены на отдельном demo-сохранении через обычные кнопки заданий, без подмены состояния или обхода mini challenge.

Сценарий A: чистый старт → A–C + mini → reload незавершённой награды → звёздная куртка → reload выбранной награды → домой и в коллекцию → D–F + mini → reload → шарик → reload → финальные 10 вопросов.
